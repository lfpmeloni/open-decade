# Product use

Version 1.1.0. Reviewed 2026-10-11; review due 2027-04-09. Applies globally to this
version of Open-decade. Primary project sources: [workflow](../workflows/local-analysis.md),
[recovery](../workflows/recovery.md), [security](../SECURITY.md), [registry](../src/capabilities.mjs).

Collect only the records needed for the question. A current balance is evidence
of a value at a date, not proof of full transaction history or acquisition cost.
Run read-only diagnostics before initialization. Preview a batch, resolve its
uncertainties, then confirm exactly that proposal. Corrections retain the original
record and create a superseding record. Explain report coverage before interpreting
a combined total. A useful partial result retains per-currency values when FX is
missing.

The local store and the external agent are separate privacy boundaries. No provider
retention promise, licensed human advisory service, or always-on monitoring is
implied. Browser and stdio interfaces call the same domain operations.
Their acceptance includes identical results, visible sources, proposal review,
monetary masking and the bounded [release accessibility baseline](../docs/release-acceptance.json). A cosmetic mask is not
redaction: share only a deliberately reviewed export.

Example: if a statement changes, preview an explicit correction and inspect the
changed report; do not edit journal files or defend an obsolete result.
